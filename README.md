# Warehouse Organization Simulation

A browser-based warehouse organization simulation embedded in a Streamlit app.

## Files
- `app.py`: Streamlit entry point
- `index.html`: interactive simulation (Amul and Reliance pages)
- `requirements.txt`: dependencies

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository and upload all files in this folder to its root.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Click **Create app** and select the repository, branch, and `app.py`.
4. Deploy.

The simulation is embedded from the HTML file; the Python wrapper does not alter its code.
